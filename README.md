# ProcTracker

A dark and pink exam day planner. It builds a time-ordered checklist for every day, scores each day, and keeps a history you can look back on. All data stays on the device (browser storage). There is no server and no account.

## Put it online with GitHub Pages (free)

1. On github.com, tap **New repository**. Name it `proctracker`. Keep it **Public** (free GitHub Pages needs a public repo). Create it.
2. Tap **uploading an existing file**, then drag in **all the files from this folder** (`index.html`, `manifest.webmanifest`, `sw.js`, the three `.png` icons, `.nojekyll`, `README.md`). Commit.
3. Open the repo's **Settings**, then **Pages**. Under **Build and deployment**, set Source to **Deploy from a branch**, Branch **main**, folder **/ (root)**. Save.
4. After a minute, your app is live at `https://YOUR-USERNAME.github.io/proctracker/`.

## Install it on an iPhone

1. Open that link in **Safari** (it must be Safari).
2. Tap **Share**, then **Add to Home Screen**, then **Add**.
3. Open it from the new ProcTracker icon. It opens full screen and works offline after the first visit.

## Sharing it

Send the link to anyone. Each person sets up their own exams, and their data stays on their own phone. Nothing is shared between people. Several people can also share one phone: use **Profiles** (tap the name at the top of any screen) to give each person separate exams, plans and scores.

## What it does

- A separate planner and checklist for every day. Use the arrows or date picker to open any day.
- Each chapter has Done, Undone and Revise, plus a priority (High, Medium, Low). High priority chapters are planned first.
- Anything not finished on a day is carried over and moved to the front of the next day.
- Every day gets a score. The Progress tab shows a calendar, averages, and a detail page for any past day.

## Updating it later

Replace `index.html` in the repo with a new version and commit. Open the app twice to pick up the update.

## Your data

Data lives in the browser on that phone. In the app, go to **Setup, then Backup and reset** to copy a backup now and then. Safari can clear stored data if you delete the app or clear website data.
